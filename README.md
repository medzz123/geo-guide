# Geo Guide

Search GeoGuessr country clues and quickly practice with a random country prompt.

## Commands

- **Search Country Clues**: Browse all country clues in a scrollable list and search by country name.
- **Random Country Clue**: Open a randomly selected country clue. Assign this command a Raycast hotkey for quick practice.

## Hotkey Setup

Open Raycast Settings, find **Geo Guide**, select **Random Country Clue**, and assign your preferred hotkey.

## Data

Geo Guide includes 136 country and territory clue entries converted into typed local data, so no network connection is required.
